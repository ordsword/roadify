**Roadify** — это высокотехнологичная интерактивная платформа с бесконечным холстом (Infinite Canvas) для визуализации дорожных карт проектов, управления спринтами, отслеживания зависимостей и **полной автоматизации через Model Context Protocol (MCP)**.

Roadify спроектирован так, чтобы внешние ИИ-агенты (**Claude Desktop, Cursor, Antigravity, OpenCode, Codex, ChatGPT**) могли подключаться к нему напрямую и выполнять любые операции: создавать спринты, декомпозировать задачи, отмечать прогресс, протягивать связи и обновлять структуру холста в режиме реального времени!

## ✨ Ключевые возможности

### 🌌 1. Бесконечный интерактивный холст (Infinite Canvas)
- **Плавное панорамирование и зум** (от 20% до 300%) с фокусировкой на курсоре мыши.
- **Точечная неоновая сетка** в стиле темного cyberpunk / modern UI.
- **Инструменты холста**: перемещение (Pan), выбор (Select), добавление карточек (Node), связывание (Connect), текстовые блоки, заметки.
- **Умное авто-выравнивание (Auto-layout)** в структурированные колонки спринта.

### 📋 2. Карточки вех и этапов (Milestone & Stage Cards)
- **Теги категорий** (`ВЕХА M0`, `ВЛАДЕЛЕЦ`, `АРТ И ЗВУК`, `ПУБЛИКАЦИЯ`).
- **Статусы с цветовой индикацией**: `✓ Готово` (зеленый), `В работе` (индиго со свечением), `Запланировано` (графит), `На паузе`.
- **Динамический прогресс-бар**: точный расчет выполненных подзадач (например, `10 из 36`, `100%`) с анимацией и салютом конфетти при завершении!
- **Иерархическое дерево чеклистов**:
  - Вложенные сворачиваемые группы задач (например, `Тулчейн через Rokit (2/2)`, `Каркас кода (0/5)`).
  - Интерактивные чекбоксы с зачеркиванием.
  - Индикаторы критического приоритета (`!`, `High`, `Critical`).
  - Быстрое добавление подзадач прямо в карточке.
- **Сроки и дедлайны** (календарные метки, например `до 23 окт.`).

### 🔗 3. Направленные кривые Безье (Bézier Dependency Links)
- Интерактивное протягивание стрелок между этапами за якорные порты.
- Настраиваемые лейблы на связях (например, `"параллельно"`, `"каркас готов"`, `"зеленый свет"`).
- Подсветка и быстрое удаление связей в один клик.

### 🧭 4. Радарный миникарта («Обзор») и Спринт-таймлайн
- **Миникарта («Обзор»)** в правом нижнем углу: мгновенная ориентация на холсте и кликабельная навигация.
- **Интерактивный таймлайн спринта**: хронологические засечки этапов по дням с быстрым переходом камеры к выбранной вехе.

### 🤖 5. Встроенный сервер Model Context Protocol (MCP)
Включает 18 мощных инструментов для ИИ:
- Поддержка **Stdio** (для локальных ИИ в Claude Desktop, Cursor, Antigravity).
- Поддержка **HTTP / Server-Sent Events (SSE)** для веб-агентов.
- **WebSocket Live-Sync**: любые изменения, сделанные ИИ, мгновенно отображаются в браузере без перезагрузки!

## 🛠️ Быстрый старт

### Требования
- Node.js 18+ (рекомендуется Node.js 20+)
- npm или pnpm

### Установка и запуск

```bash
# Клонирование репозитория
git clone https://github.com/ordsword/roadify.git
cd roadify

# Установка зависимостей
npm install

# Запуск единого сервера (API + WebSocket + статика)
npm start

# Либо запуск frontend в режиме разработки (HMR)
npm run dev
```

Приложение будет доступно по адресу: **http://localhost:3001** (или **http://localhost:5173** в режиме Vite dev).

## 🤖 Подключение ИИ к Roadify через MCP

### 1. Claude Desktop
Добавьте следующий фрагмент в конфигурационный файл Claude Desktop:
- **Windows**: `%APPDATA%\Claude\claude_desktop_config.json`
- **macOS**: `~/Library/Application Support/Claude/claude_desktop_config.json`

```json
{
  "mcpServers": {
    "roadify": {
      "command": "node",
      "args": ["<ПУТЬ_К_РЕПОЗИТОРИЮ>/server/mcp-server.ts"]
    }
  }
}
```

### 2. Cursor IDE
В Cursor перейдите в **Settings** → **Features** → **MCP Servers** → **Add New MCP Server**:
- **Name**: `roadify`
- **Type**: `command`
- **Command**: `node <ПУТЬ_К_РЕПОЗИТОРИЮ>/server/mcp-server.ts`

### 3. Antigravity & Gemini CLI
Добавьте в список MCP серверов:
```json
{
  "command": "node",
  "args": ["<ПУТЬ_К_РЕПОЗИТОРИЮ>/server/mcp-server.ts"]
}
```

## 🧰 Список MCP инструментов (Tools)

| Инструмент | Описание |
| :--- | :--- |
| `list_roadmaps` | Получить список всех дорожных карт со статистикой и процентом выполнения. |
| `get_roadmap` | Получить полную структуру дорожной карты (этапы, задачи, группы, связи). |
| `create_roadmap` | Создать новую дорожную карту / спринт проект. |
| `update_roadmap` | Обновить метаданные дорожной карты (название, описание, автор). |
| `delete_roadmap` | Удалить дорожную карту. |
| `add_stage` | Добавить новый этап / карточку на холст (координаты, тег, описание, дедлайн, приоритет). |
| `update_stage` | Обновить статус, заголовок, дедлайн или позицию этапа на холсте. |
| `delete_stage` | Удалить этап с холста и отключить связанные стрелки. |
| `add_task_group` | Добавить группу задач / категорию чеклиста в этап. |
| `add_subtask` | Добавить задачу в этап или группу. |
| `toggle_subtask` | Отметить задачу выполненной / невыполненной (авто-пересчет прогресса). |
| `update_subtask` | Отредактировать текст или приоритет задачи. |
| `delete_subtask` | Удалить задачу. |
| `create_connection` | Создать направленную стрелку зависимости между двумя этапами с подписью. |
| `delete_connection` | Удалить стрелку зависимости. |
| `auto_layout` | Автоматически расставить этапы по аккуратной сетке спринта. |
| `generate_sprint_plan` | Сгенерировать полноценный спринт с группами, задачами и связями по цели. |
| `export_markdown_report` | Сгенерировать подробный Markdown отчет для репозитория или GitHub Release. |
